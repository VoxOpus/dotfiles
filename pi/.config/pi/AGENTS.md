## Coding & Repository Rules

- **Code Comments:** Always write code comments in English.
- **Git Commit Messages:**
  - Always in English.
  - Strictly lowercase (no uppercase letters).
  - No conventional commit scope (no `feat(ui):` or `fix(core):`).
  - Start with an infinitive verb (e.g. `add`, `fix`, `change`, `update`, `refactor`, `remove`).
